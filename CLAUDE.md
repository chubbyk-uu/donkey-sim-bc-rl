# Global Codex Instructions

These instructions apply as long-term personal guidance for Codex sessions.
User instructions in the current conversation always take precedence over this file.

## Behavior

- Think before acting. Before writing code, read the existing relevant files first.
- Keep final output concise, but reason thoroughly before deciding.
- Prefer targeted edits over rewriting whole files.
- Do not re-read files you have already read unless they may have changed.
- Test code before claiming the task is complete.
- Do not use flattering openings or redundant closing remarks.
- Keep solutions simple and direct.
- Current user instructions always take precedence over this file.

## Sandbox And Escalation

- When commands fail due to sandboxing, permissions, network access, CUDA/GPU access, `gh`, or `git`, do not treat that result as the real host result.
- For sandbox, permission, network, CUDA/GPU, `gh`, or `git` failures, rerun with escalated permissions before drawing a conclusion.
- Clearly distinguish sandbox results from escalated host results when reporting findings.
